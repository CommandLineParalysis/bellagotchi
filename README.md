# Bellagotchi

Ein ruhiges Pflegespiel in Pixeloptik für Android, offline. Teil des
B-Appiverse.

Fünf Zimmer — Schlafzimmer, Küche, Wohnzimmer, Bad, Kleiderschrank —, eine
Bella, und nichts, was schiefgehen kann.

```
npm install
npm test
npm run setup:android    # einmalig
npm run open             # Android Studio
```

Die Pixelbilder stehen als Textraster in `www/js/sprites.js`. Es werden
keine Bilddateien geladen; die App braucht kein Netz.
